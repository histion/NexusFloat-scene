# 2026-09-25

## 第十二轮（v8.8.9.4）：修复充电功率曲线断续（假 0 采样）+ 统计页拆成「充电/使用」两模块

用户两点需求 + 版本迭代到 8.8.9.4。

### 1. 假 0 采样（充电功率曲线断续）
**病灶**：读不到电流/功率的采样点被原样落库成 `power_w=0`。曲线表现为「多数点贴 0、
偶尔窜一根 ~50W 尖峰」，平均功率被系统性拖低（用户截图：平均 20.3W vs 峰值 52.9W）。

**改法**（关键设计）：
- `PowerTracker` 加 `lastFresh` / `lastWasFresh()`：各返回路径标记「是否本拍新读到」。
- `BatterySampler` 加 `lastValidCurrentA` / `chargeCarryTicks`：充电时读不到就沿用上次
  有效电流，上限 `Constants.Battery.CHARGE_CARRY_MAX_TICKS = 40` 拍；沿用值仍写进
  `power_w`/`current_ma`（充电积分继续用），但 `s.powerKnown = currentFresh || (!carriedCurrent && powerTracker.lastWasFresh())`；拔电 `chargeCarryTicks` 归零。
- `Constants.Battery.CURRENT_MAX_A` 12f → 20f（不再把 >12A 真快充当非法值丢）。
- `Stats.DB_VERSION` 1 → 2；`samples` 新增 `power_known INTEGER NOT NULL DEFAULT 1`。
- `StatsStore.aggregate()` 平均功率改 **dt 加权 + 只算 power_known=1**，峰值也只取已知点；
  `queryAppUsage()` 同口径。
- `StatsScreen.chargePowerSeries()`：未知点用**前一个有效值桥接**（不画假 0、不留空洞），
  首个有效点之前为 `null`（折线断开），整段全未知才回退原始绝对值。

### 2. 统计页拆分
`StatsScreen` 加 `section`（rememberSaveable）+ `SegmentedSelector("充电统计","使用统计")`：
- 充电模块：ChargeCard → HistoryCard → **ChargeTotalsCard** → **ChargeSettingsCard**
- 使用模块：UsageCard → AppUsageCard → PeriodHistoryCard → **UsageTotalsCard** → **UsageSettingsCard**
- 旧的 `TotalsCard` / `StatsSettingsCard` 已删（拆成充电/使用各一张）。
- 设置项映射（一个不少）：开统计/采样间隔/常驻通知/双电芯/电流诊断/采样点数+清空 → 充电；
  仅亮屏时记录/使用情况访问 → 使用。
