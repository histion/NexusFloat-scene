## 第二十一轮（v9.0.0.6）：悬浮球转屏丢失修复 + 设备信息卡换自绘图标

### 1. 悬浮球横屏挪到边缘后，转回竖屏捞不回来（用户报的 bug）
**根因**：`FrameBubble` 的位置按**绝对像素**存（KEY_X/KEY_Y），窗口又带
`FLAG_LAYOUT_NO_LIMITS`。横屏 2400 宽时拖到最右存下 x=2268，转竖屏画面只剩 1080 宽，
球被留在屏幕外——看不见也点不到，系统不会替我们把坐标收回屏幕内。

**改法**：
- 位置改存**比例**（`frame_bubble_fx` / `frame_bubble_fy`，0..1，相对「屏幕尺寸 − 球尺寸」
  的可移动范围）。横屏贴右边存 fx=1.0，竖屏回来落在竖屏的右边沿，转回横屏还在原位。
  旧的绝对像素键**保留不删**：没有比例键时读老值换算一次并夹取，升级后第一次打开
  自动回到屏幕内。
- 新增 `reposition()`：屏幕变了就按比例重算 + 夹取 + `updateViewLayout`。触发三路——
  `DisplayManager.DisplayListener.onDisplayChanged`（主）、
  `ComponentCallbacks.onConfigurationChanged`（兜底）、`BallView.onConfigurationChanged`（再兜底）；
  两个监听只在显示期间挂，`hide()` 里注销。
- **`screenSize()` 必须问 `Display.getRealSize()`**，不能用
  `context.getResources().getDisplayMetrics()`——那是 App 的配置，转屏后要等系统把配置
  推过来才更新，回调里读到的还是旧值。
- 顺带修 `clampY`：原来只写了 `Math.max(0, ...)`，往下也能拖出屏幕，同样是捞不回来。
- 离线复刻新逻辑跑了 4 个场景（横屏贴右→竖屏贴右→转回原位、贴左、老像素兼容、往下夹取），全过。

### 2. 设备信息卡：emoji → 用户给的自绘 SVG
- 用户给了 3 个 48×48 SVG（芯片 #4a90e2 / 安卓机器人 #79ce19 / 手机 #333）。
  **深色卡片上原来的黑色描边根本看不见**，所以每个图标拆两层：
  `*_accent`（品牌色填充，保留原色）+ `*_ink`（线条，矢量里画纯白，运行时按
  `MdThemeOnSurface` tint）。两层叠起来才等于原图。手机图标没有品牌色，单层即可；
  原图那条白色 home 线改成「在下巴上挖洞」（`fillType="evenOdd"`），洞露的是卡片底色，
  换主题自动跟着走，不需要第二层去凑背景色。
- `MetricTile` 的 `icon: String?` 换成 `iconRes` / `iconAccentRes: Int?`；logo 摆**标题行**左边
  （原来 emoji 的位置），数值行仍占满整格宽度。
- **布局抉择（记一下，免得下次再纠结）**：用户草图画的是「logo 占左侧、标题+数值整体在右边」，
  但问过之后他的原话是「保持原本的布局，只改动里面的内容」。用 Pillow 出预览实测，
  那个排法会把数值栏从 97dp 压到 75dp，「SM-S9280」这种机型号会贴着截断线走，
  所以按他说的保持了原布局。
